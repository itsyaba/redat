# M1 plan — It can actually do things

## What I found on the machine (2026-10-15)

- Hyprland 0.56 with **Lua config**: `hyprctl dispatch` takes a Lua expression, so the old syntax (`dispatch workspace 3`) fails. Verified working:
  - `hyprctl dispatch 'hl.dsp.focus({ workspace = 3 })'`
  - `hyprctl dispatch 'hl.dsp.window.move({ workspace = 9, follow = false, window = "class:kitty" })'`
  - `hyprctl dispatch 'hl.dsp.window.close({ window = "class:kitty" })'`
  - `hyprctl dispatch 'hl.dsp.exec_cmd("uwsm app -- kitty", { workspace = "9 silent" })'`
  - API stubs: `/usr/share/hypr/stubs/hl.meta.lua`
- Shell: Caelestia (`caelestia` CLI). Apps: zen-browser (browser), firefox, kitty, codium, thunar; Spotify, Slack and Telegram (materialgram) live in special workspaces.
- `claude -p` with `--setting-sources "" --strict-mcp-config` takes ~6s instead of ~13s and has 9k context instead of 72k. It still uses the subscription (OAuth). `--bare` can't use it (API key only).

## Changes

1. **Split the spike into modules** (M2 needs this anyway): `config.ts`, `audio.ts`, `addis.ts`, `brain.ts`, `prompt.ts`, `log.ts`; `spike.ts` becomes a thin entry point.
2. **Brain with tools:** `claude -p --tools Bash,WebSearch --permission-mode bypassPermissions --setting-sources "" --strict-mcp-config --output-format stream-json --verbose`. Parse the stream so I can see each tool call.
3. **Command log:** every Bash call (command, output, error flag, timestamp) is appended as JSONL to `~/.local/state/redat/commands.log`.
4. **Desktop context per turn:** the user message gets a compact snapshot first (monitors, active workspace, windows), so Claude rarely needs an extra round trip just to look.
5. **System prompt:** machine facts, a cheat sheet for the Lua dispatch syntax, launch rules (always `exec_cmd` + `uwsm app --`, never run GUI apps in the foreground of Bash), the system commands available, and rules for spoken replies.
6. **Working directory:** `~/.local/state/redat/work` instead of the repo's `tmp/`.
